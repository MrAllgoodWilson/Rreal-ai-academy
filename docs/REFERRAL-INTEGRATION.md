# Referral foundation — local, disabled; integration acceptance required

Owner requested: after first settled $1 payment show code/link/QR; every20 distinct newly paid referred learners earns$10 project credits and a persistent dashboard notice. This scaffold does not claim live readiness, automatic wallet fulfillment, uniquely human/referral-fraud verification or profitable economics.

## Implemented
- New migration0006 only: opaque referral profiles, immutable signup attribution, first-payment registry, held qualification, repeatable reward cohorts and durable notification acknowledgment.
- Service-only qualifying receipt RPC. Accepts only100 US cents, USD, nonfuture paid timestamp and distinct user/customer/session. Authenticated users cannot qualify their own payment or read raw referred identities/payment records.
- Attribution must occur before first payment; locks learner profile against payment races; first referral wins, no self referral. Codes are visible only after trusted first-paid registration. New payment proof required for existing members; don't backfill from subscription status alone.
- A default30-day hold is a PROPOSED fraud/refund safeguard and must be accepted before feature activation. Configurable reviewed policy threshold20/reward1000 cents. Refunded/disputed pending referrals excluded; affected issued rewards flagged for manual review, never silent cash clawback. No recurring renewal counted.
- Own authenticated dashboard RPC serializes milestone processing and groups exactly20 previously-unrewarded qualified new members per cohort. Every cohort has a unique milestone and one reward record; duplicate/concurrent dashboard reads cannot grant duplicate entitlements.
- `/api/referrals` gated by `REFERRALS_ENABLED=true`, off by default. GET returns own aggregate counts/rewards plus local QR for first-party signup URL; POST attributes a code or dismisses owned notice. UI component `ReferralPanel` is supplied but not mounted in shared dashboard.
- Reward is a$10 entitlement with `pending_wallet` status, not a fake credit balance. Existing project wallet absent. Legacy video/course balances and migration0004 untouched.
